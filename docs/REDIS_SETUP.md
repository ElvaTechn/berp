# Configuração Redis - Tutorial Completo
# ====================================

# 1. Acesse: https://console.upstash.com/
# 2. Crie conta gratuita
# 3. Clique "Create Database"
# 4. Escolha região (ex: São Paulo, Brazil)
# 5. Nomeie como "berp-ratelimit"
# 6. Clique "Create"

# 7. Na página do banco, copie:
# UPSTASH_REDIS_REST_URL=https://your-database-id.upstash.io
# UPSTASH_REDIS_REST_TOKEN=your-secret-token

# 8. Cole aqui embaixo:
UPSTASH_REDIS_REST_URL=
UPSTASH_REDIS_REST_TOKEN=

# 9. Salve este arquivo como .env.production
# 10. Execute: npm run build
